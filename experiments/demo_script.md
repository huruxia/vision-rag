# CP1 Demo 脚本（5 分钟）

目标：证明三件事——① 会答自己的文档 ② 不知道就说不知道 ③ 便宜到离谱
环境：PS > uv run python main.py（提前开好终端，不现场等待加载）

【0:00-0:30 开场】
"我搭了一个 RAG 系统，让它读我自己的 4 篇技术笔记。一共 179 行代码。
现在演示三件事：它会答、它会拒答、它很便宜。"

【0:30-2:00 有答案三连】
问题: 什么是RAG
问题: 为什么要分块
问题: 什么是智能体
（每个答完等 2 秒，指屏幕："注意，答案里有'资料里提到的……'，这是它基于我的笔记答的"）

【2:00-3:00 反差拒答】
问题: 开心是谁的小猫
问题: 今天上海天气怎么样
（指屏幕："看到了吗——它没瞎编，直接说不知道。这是 0.45 的置信度闸门在拦截"）

【3:00-4:00 成本暴击】
PS> uv run python cost_report.py
（指输出："从开发到评测，全部 API 花费：X 元。不到一瓶矿泉水。"）

【4:00-4:30 架构一句话】
"底层是四步：切块 → 嵌入 → 混合检索(BM25+向量) → Rerank 精排 → 置信度闸门 → 生成。
Recall@1 从 0.90 提升到 1.00，忠实率 10/10。"

【4:30-5:00 收尾】
"以上就是我的第一个里程碑。谢谢，欢迎提问。"
