# temperature 实验（2026-10-24）

问题：给一只叫开心的小猫编一句广告词

| 温度 | 回答 |
|---|---|
| 0.2 | 开心小猫，一爪拍走不开心！ |
| 0.9 | 开心小猫，一喵就把快乐带回家！ |
| 1.5 | “开心小猫，把快乐带回家！” |

观察：
- 三个回答都扣住 "开心" 双关（猫名 + 情绪）：0.2 最工整押韵，0.9 最口语生动，1.5 反而最朴素。
- 推测：温度低 → 模型更倾向选 "最可能的词" → 结果四平八稳、像正经广告；温度高 → 允许选低概率词，但每次是随机采样——1.5 这次运气好采到了朴素组合。
- 结论：高温 ≠ 必然花哨；单次采样不能下结论，同一温度要多跑几次看分布。

（方法瑕疵：每次重开程序 = 独立会话，控制变量 OK）
